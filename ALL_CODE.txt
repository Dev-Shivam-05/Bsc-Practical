Q: Write a shell script to accept two numbers and perform addition, subtraction, multiplication, division, and modulus using arithmetic operators.
==============================================================================

----- FILE: code/UX-A2-01/q01.sh -----
#!/usr/bin/env bash
read -r -p "Enter two integers: " a b
if ! [[ $a =~ ^-?[0-9]+$ && $b =~ ^-?[0-9]+$ ]]; then
  echo "Please enter valid integers."; exit 1
fi

echo "Subtraction: $((a - b))"

  echo "Division and modulus are undefined for zero divisor."
else
  echo "Division: $((a / b))"
  echo "Modulus: $((a % b))"
fi

  [[ $n =~ ^-?[0-9]+$ ]] || { echo "Invalid integer."; exit 1; }

UX-A2-12  Menu-driven calculator (case)
Q: Write a menu-driven shell script using case to perform addition, subtraction, multiplication, division, modulus, and exit operations.
==============================================================================

----- FILE: code/UX-A2-12/q12.sh -----
#!/usr/bin/env bash
while true; do
  printf '\n1. Add  2. Subtract  3. Multiply  4. Divide\n'
  printf '5. Modulus  6. Exit\n'
  read -r -p "Choose 1-6: " choice
  case "$choice" in
    6) echo "Goodbye"; break ;;
    1|2|3|4|5) ;;
    *) echo "Invalid choice"; continue ;;
  esac
  read -r -p "Enter two integers: " a b
  if ! [[ $a =~ ^-?[0-9]+$ && $b =~ ^-?[0-9]+$ ]]; then
    echo "Invalid integer input"; continue
  fi
  if [[ $choice == 4 || $choice == 5 ]] && ((b == 0)); then
    echo "Cannot use zero as divisor"; continue
  fi
  case "$choice" in
    1) answer=$((a+b)) ;; 2) answer=$((a-b)) ;;
    3) answer=$((a*b)) ;; 4) answer=$((a/b)) ;;
    5) answer=$((a%b)) ;;
  esac
  echo "Result: $answer"
done

read -r -p "Enter path: " path
if [[ ! -e $path ]]; then echo "Path does not exist"; exit 0; fi
echo "Path exists"
if [[ -f $path ]]; then echo "Regular file";
elif [[ -d $path ]]; then echo "Directory";
else echo "Other file type"; fi
for mode in read write execute; do
  case "$mode" in
    read)    testflag=-r ;; write) testflag=-w ;;
    execute) testflag=-x ;;
  esac
  if test "$testflag" "$path"; then
    echo "$mode permission: yes"
  else
    echo "$mode permission: no"
  fi
done

#!/usr/bin/env bash
factorial() {
  local n=$1 result=1 i
  if ! [[ $n =~ ^[0-9]+$ ]]; then
    echo "Factorial requires a non-negative integer"; return 1
  fi
  for ((i=2; i<=n; i++)); do ((result *= i)); done
  printf 'Factorial of %d = %d\n' "$n" "$result"
}

UX-P2-09  Menu-driven calculator (same as UX-A2-12)
Q: Create a menu-driven calculator using the case statement for: Addition, Subtraction, Multiplication, Division, Exit
==============================================================================

----- FILE: code/UX-P2-09/q12.sh -----
#!/usr/bin/env bash
while true; do
  printf '\n1. Add  2. Subtract  3. Multiply  4. Divide\n'
  printf '5. Modulus  6. Exit\n'
  read -r -p "Choose 1-6: " choice
  case "$choice" in
    6) echo "Goodbye"; break ;;
    1|2|3|4|5) ;;
    *) echo "Invalid choice"; continue ;;
  esac
  read -r -p "Enter two integers: " a b
  if ! [[ $a =~ ^-?[0-9]+$ && $b =~ ^-?[0-9]+$ ]]; then
    echo "Invalid integer input"; continue
  fi
  if [[ $choice == 4 || $choice == 5 ]] && ((b == 0)); then
    echo "Cannot use zero as divisor"; continue
  fi
  case "$choice" in
    1) answer=$((a+b)) ;; 2) answer=$((a-b)) ;;
    3) answer=$((a*b)) ;; 4) answer=$((a/b)) ;;
    5) answer=$((a%b)) ;;
  esac
  echo "Result: $answer"
done

Program 4 - Demonstrate MSIL compilation
==========================================

1. Compile the VB source to an assembly (MSIL inside a PE file):
     C:\Windows\Microsoft.NET\Framework64\v4.0.30319\vbc.exe /target:exe /out:Hello.exe Hello.vb
   (In "Developer Command Prompt for VS" you can type just: vbc /target:exe /out:Hello.exe Hello.vb)

2. Run it (the CLR JIT-compiles the IL to native code at run time):
     Hello.exe
   Expected output:  Hello from managed .NET code

3. Inspect the MSIL with ildasm:
     GUI : ildasm Hello.exe        -> expand "Hello" -> double-click "Main : void()"
     Text: ildasm /text Hello.exe   (prints the IL to the console)
   ildasm is not on the normal PATH. Full path on a machine with Visual Studio / .NET SDK:
     "C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8.1 Tools\ildasm.exe"

   Expected IL for Main (verified):
     IL_0000:  ldstr      "Hello from managed .NET code"
     IL_0005:  call       void [mscorlib]System.Console::WriteLine(string)
     IL_000a:  ret

If Windows blocks Hello.exe ("file contains a virus or potentially unwanted software",
caused by Smart App Control / Defender on brand-new unsigned exe files), build a DLL instead
and inspect that - the IL of Main is identical:
     vbc /target:library /out:HelloLib.dll Hello.vb

Imports System.Configuration
Imports System.Data
Imports System.Data.SqlClient

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

Imports System.Configuration
Imports System.Data
Imports System.Data.SqlClient

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

Imports System
Imports System.Data
Imports System.Data.SqlClient
Imports System.Globalization

Partial Class Prog4
    Inherits System.Web.UI.Page

    Protected Sub Page_Load(sender As Object, e As EventArgs)
        If Not IsPostBack Then BindGrid()
    End Sub

    Private Sub BindGrid()
        gvData.DataSource = Db.ReadTable(
            "SELECT * FROM Employee ORDER BY EmployeeID")
        gvData.DataBind()
    End Sub

    Private Function FormParams() As SqlParameter()
        If String.IsNullOrWhiteSpace(txtEmployeeName.Text) Then
            Throw New ArgumentException("Employee name is required.")
        End If
        If String.IsNullOrWhiteSpace(txtDepartment.Text) Then
            Throw New ArgumentException("Department is required.")
        End If
        If String.IsNullOrWhiteSpace(txtSalary.Text) Then
            Throw New ArgumentException("Salary is required.")
        End If
        If String.IsNullOrWhiteSpace(txtContactNo.Text) Then
            Throw New ArgumentException("Contact no. is required.")
        End If
        Return New SqlParameter() {
            New SqlParameter("@EmployeeName", txtEmployeeName.Text.Trim()),
            New SqlParameter("@Department", txtDepartment.Text.Trim()),
            New SqlParameter("@Salary", Decimal.Parse(txtSalary.Text, CultureInfo.InvariantCulture)),
            New SqlParameter("@ContactNo", txtContactNo.Text.Trim())
        }
    End Function

    Private Sub ResetForm()
        txtEmployeeName.Text = ""
        txtDepartment.Text = ""
        txtSalary.Text = ""
        txtContactNo.Text = ""
        hfKey.Value = ""
        gvData.SelectedIndex = -1
    End Sub

    Protected Sub btnAdd_Click(sender As Object, e As EventArgs)
        Try
            Db.Execute("INSERT INTO Employee (EmployeeName,Department,Salary,ContactNo) " &
                "VALUES (@EmployeeName,@Department,@Salary,@ContactNo)", FormParams())
            lblMessage.Text = "Record inserted."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Insert failed: check all field values."
        End Try
    End Sub

    Protected Sub btnUpdate_Click(sender As Object, e As EventArgs)
        If hfKey.Value = "" Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Try
            Dim ps As New List(Of SqlParameter)(FormParams())
            ps.Add(New SqlParameter("@Key", Integer.Parse(hfKey.Value)))
            Db.Execute("UPDATE Employee SET EmployeeName=@EmployeeName,Department=@Department,Salary=@Salary,ContactNo=@ContactNo WHERE EmployeeID=@Key", ps.ToArray())
            lblMessage.Text = "Record updated."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Update failed: check all field values."
        End Try
    End Sub

    Protected Sub btnDelete_Click(sender As Object, e As EventArgs)
        Dim key As Integer
        If Not Integer.TryParse(hfKey.Value, key) Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Db.Execute("DELETE FROM Employee WHERE EmployeeID=@Key",
            New SqlParameter("@Key", key))
        lblMessage.Text = "Record deleted."
        ResetForm()
        BindGrid()
    End Sub

    Protected Sub btnClear_Click(sender As Object, e As EventArgs)
        ResetForm()
        lblMessage.Text = ""
    End Sub

    Protected Sub gvData_SelectedIndexChanged(sender As Object, e As EventArgs)
        Dim key As Integer = Convert.ToInt32(gvData.SelectedDataKey.Value)
        Dim data As DataTable = Db.ReadTable(
            "SELECT * FROM Employee WHERE EmployeeID=@Key",
            New SqlParameter("@Key", key))

Public NotInheritable Class Db
    Private Sub New()
    End Sub

        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function

    End Sub

    Private Sub BindGrid()
        gvData.DataSource = Db.ReadTable(
            "SELECT * FROM Customer ORDER BY CustomerID")
        gvData.DataBind()
    End Sub

    Private Function FormParams() As SqlParameter()
        If String.IsNullOrWhiteSpace(txtCustomerName.Text) Then
            Throw New ArgumentException("Customer name is required.")
        End If
        If String.IsNullOrWhiteSpace(txtEmail.Text) Then
            Throw New ArgumentException("Email is required.")
        End If
        If String.IsNullOrWhiteSpace(txtPhone.Text) Then
            Throw New ArgumentException("Phone is required.")
        End If
        If String.IsNullOrWhiteSpace(txtAddress.Text) Then
            Throw New ArgumentException("Address is required.")
        End If
        Return New SqlParameter() {
            New SqlParameter("@CustomerName", txtCustomerName.Text.Trim()),
            New SqlParameter("@Email", txtEmail.Text.Trim()),
            New SqlParameter("@Phone", txtPhone.Text.Trim()),
            New SqlParameter("@Address", txtAddress.Text.Trim())
        }
    End Function

    Private Sub ResetForm()
        txtCustomerName.Text = ""
        txtEmail.Text = ""
        txtPhone.Text = ""
        txtAddress.Text = ""
        hfKey.Value = ""
        gvData.SelectedIndex = -1
    End Sub

    Protected Sub btnAdd_Click(sender As Object, e As EventArgs)
        Try
            Db.Execute("INSERT INTO Customer (CustomerName,Email,Phone,Address) " &
                "VALUES (@CustomerName,@Email,@Phone,@Address)", FormParams())
            lblMessage.Text = "Record inserted."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Insert failed: check all field values."
        End Try
    End Sub

    Protected Sub btnUpdate_Click(sender As Object, e As EventArgs)
        If hfKey.Value = "" Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Try
            Dim ps As New List(Of SqlParameter)(FormParams())
            ps.Add(New SqlParameter("@Key", Integer.Parse(hfKey.Value)))
            Db.Execute("UPDATE Customer SET CustomerName=@CustomerName,Email=@Email,Phone=@Phone,Address=@Address WHERE CustomerID=@Key", ps.ToArray())
            lblMessage.Text = "Record updated."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Update failed: check all field values."
        End Try
    End Sub

    Protected Sub btnDelete_Click(sender As Object, e As EventArgs)
        Dim key As Integer
        If Not Integer.TryParse(hfKey.Value, key) Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Db.Execute("DELETE FROM Customer WHERE CustomerID=@Key",
            New SqlParameter("@Key", key))
        lblMessage.Text = "Record deleted."
        ResetForm()
        BindGrid()
    End Sub

    Protected Sub btnClear_Click(sender As Object, e As EventArgs)
        ResetForm()
        lblMessage.Text = ""
    End Sub

Imports System.Configuration
Imports System.Data
Imports System.Data.SqlClient

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

Imports System

Partial Class Prog7
    Inherits System.Web.UI.Page

    Protected Sub Page_Load(sender As Object, e As EventArgs)
        If Not IsPostBack Then BindGrid()
    End Sub

    Private Sub BindGrid()
        gvData.DataSource = Db.ReadTable(
            "SELECT * FROM Medicine ORDER BY MedicineID")
        gvData.DataBind()
    End Sub

    Private Function FormParams() As SqlParameter()
        If String.IsNullOrWhiteSpace(txtMedicineName.Text) Then
            Throw New ArgumentException("Medicine name is required.")
        End If
        If String.IsNullOrWhiteSpace(txtCategory.Text) Then
            Throw New ArgumentException("Category is required.")
        End If
        If String.IsNullOrWhiteSpace(txtPrice.Text) Then
            Throw New ArgumentException("Price is required.")
        End If
        If String.IsNullOrWhiteSpace(txtQuantity.Text) Then
            Throw New ArgumentException("Quantity is required.")
        End If
        If String.IsNullOrWhiteSpace(txtExpiryDate.Text) Then
            Throw New ArgumentException("Expiry date is required.")
        End If
        Return New SqlParameter() {
            New SqlParameter("@MedicineName", txtMedicineName.Text.Trim()),
            New SqlParameter("@Category", txtCategory.Text.Trim()),
            New SqlParameter("@Price", Decimal.Parse(txtPrice.Text, CultureInfo.InvariantCulture)),
            New SqlParameter("@Quantity", Integer.Parse(txtQuantity.Text, CultureInfo.InvariantCulture)),
            New SqlParameter("@ExpiryDate", DateTime.ParseExact(txtExpiryDate.Text, "yyyy-MM-dd", CultureInfo.InvariantCulture))
        }
    End Function

    Private Sub ResetForm()
        txtMedicineName.Text = ""
        txtCategory.Text = ""
        txtPrice.Text = ""
        txtQuantity.Text = ""
        txtExpiryDate.Text = ""
        hfKey.Value = ""
        gvData.SelectedIndex = -1
    End Sub

    Protected Sub btnAdd_Click(sender As Object, e As EventArgs)
        Try
            Db.Execute("INSERT INTO Medicine (MedicineName,Category,Price,Quantity,ExpiryDate) " &
                "VALUES (@MedicineName,@Category,@Price,@Quantity,@ExpiryDate)", FormParams())
            lblMessage.Text = "Record inserted."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Insert failed: check all field values."
        End Try
    End Sub

    Protected Sub btnUpdate_Click(sender As Object, e As EventArgs)
        If hfKey.Value = "" Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Try
            Dim ps As New List(Of SqlParameter)(FormParams())
            ps.Add(New SqlParameter("@Key", Integer.Parse(hfKey.Value)))
            Db.Execute("UPDATE Medicine SET MedicineName=@MedicineName,Category=@Category,Price=@Price,Quantity=@Quantity,ExpiryDate=@ExpiryDate WHERE MedicineID=@Key", ps.ToArray())
            lblMessage.Text = "Record updated."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Update failed: check all field values."
        End Try
    End Sub

    Protected Sub btnDelete_Click(sender As Object, e As EventArgs)
        Dim key As Integer
        If Not Integer.TryParse(hfKey.Value, key) Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Db.Execute("DELETE FROM Medicine WHERE MedicineID=@Key",
            New SqlParameter("@Key", key))
        lblMessage.Text = "Record deleted."
        ResetForm()
        BindGrid()
    End Sub

    Protected Sub btnClear_Click(sender As Object, e As EventArgs)
        ResetForm()
        lblMessage.Text = ""
    End Sub

    Protected Sub gvData_SelectedIndexChanged(sender As Object, e As EventArgs)
        Dim key As Integer = Convert.ToInt32(gvData.SelectedDataKey.Value)
        Dim data As DataTable = Db.ReadTable(
            "SELECT * FROM Medicine WHERE MedicineID=@Key",
            New SqlParameter("@Key", key))
        If data.Rows.Count = 0 Then Return
        Dim row As DataRow = data.Rows(0)
        hfKey.Value = key.ToString()
        txtMedicineName.Text = row("MedicineName").ToString()
        txtCategory.Text = row("Category").ToString()
        txtPrice.Text = Convert.ToDecimal(row("Price")).ToString(CultureInfo.InvariantCulture)
        txtQuantity.Text = row("Quantity").ToString()
        txtExpiryDate.Text = CDate(row("ExpiryDate")).ToString("yyyy-MM-dd")
    End Sub

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;
}

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;
}

function db(array $model): PDO {
    static $db = null;
    if ($db instanceof PDO) return $db;
    $host = getenv('DB_HOST') ?: '127.0.0.1';
    $user = getenv('DB_USER') ?: 'root';
    $pass = getenv('DB_PASSWORD') ?: '';
    $database = $model['database'];
    $dsn = "mysql:host=$host;dbname=$database;charset=utf8mb4";
    $db = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]);
    return $db;
}

<?php
function render_rows(array $records, array $model): void {
    if (!$records) {
        echo '<tr><td colspan="' . (count($model['fields']) + 2) . '">'
            . 'No matching records.</td></tr>';
        return;
    }
    foreach ($records as $row) {
        echo '<tr><td>' . e($row[$model['pk']]) . '</td>';
        foreach (array_keys($model['fields']) as $name) {
            echo '<td>' . e($row[$name]) . '</td>';
        }
        $id = (int)$row[$model['pk']];
        echo '<td><a href="edit.php?id=' . $id . '">Edit</a> ';
        echo '<form class="inline" method="post" action="delete.php"'
             . ' onsubmit="return confirm(&quot;Delete this record?&quot;)">';
        echo '<input type="hidden" name="id" value="' . $id . '">';
        echo '<input type="hidden" name="csrf" value="' . e(token()) . '">';
        echo '<button type="submit">Delete</button></form></td></tr>';
    }
}

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;
}

----- FILE: code/UX-T1-01/answer.txt -----
Q: Q1. What is an Operating System?

What is an Operating System?

An Operating System (OS) is system software that acts as an interface between the user/application programs and the computer hardware. It manages hardware resources and provides common services to programs.

Main functions:
1. Process management - creates, schedules and terminates processes (programs in execution).
2. Memory management - allocates and frees main memory for processes.
3. File management - creates, deletes, organises and protects files and directories.
4. Device (I/O) management - controls devices through device drivers.
5. Security and protection - user login, passwords, file permissions.
6. User interface - command line (shell) or graphical interface (GUI).

Examples: UNIX, Linux, Windows, macOS, Android.

UX-T1-02  Explain the Types of Operating Systems.
Q: Q2. Explain the Types of Operating Systems.
==============================================================================

----- FILE: code/UX-T1-02/answer.txt -----
Q: Q2. Explain the Types of Operating Systems.

Types of Operating Systems

1. Batch OS - similar jobs are collected into batches and run one after another without user interaction. Example: early IBM mainframe systems.
2. Multiprogramming OS - several programs are kept in memory; when one waits for I/O the CPU runs another, so CPU is never idle.
3. Time-sharing (Multitasking) OS - CPU time is divided into small time slices given to each user/process in turn, so many users feel they have the computer to themselves. Example: UNIX.
4. Multiprocessing OS - uses two or more CPUs that share memory to run processes in parallel. Example: Linux on multi-core systems.
5. Distributed OS - many independent computers connected by a network work together and appear as one system.
6. Network OS - runs on a server and provides file sharing, printers, users and security over a network. Example: Windows Server, Novell NetWare.
7. Real-Time OS (RTOS) - gives a response within a fixed time limit. Hard real-time (missile, pacemaker) and soft real-time (video streaming). Example: VxWorks, FreeRTOS.
8. Mobile / Embedded OS - designed for phones and devices with limited resources. Example: Android, iOS.

UX-T1-05  Explain the History of UNIX.
Q: Q5. Explain the History of UNIX.
==============================================================================

----- FILE: code/UX-T1-05/answer.txt -----
Q: Q5. Explain the History of UNIX.

History of UNIX

- 1965-1969: Bell Labs, MIT and General Electric worked on MULTICS. Bell Labs left the project.
- 1969: Ken Thompson and Dennis Ritchie at AT&T Bell Labs wrote the first UNIX on a PDP-7 computer, in assembly language.
- 1971: First edition of UNIX released on PDP-11.
- 1973: UNIX was rewritten in the C language (created by Dennis Ritchie). This made UNIX portable to other machines.
- Late 1970s: AT&T gave UNIX source code to universities. University of California, Berkeley developed BSD (Berkeley Software Distribution), adding TCP/IP networking and the vi editor.
- 1983: AT&T released System V. UNIX split into two main families: System V and BSD.
- 1980s-1990s: Commercial versions appeared: SunOS/Solaris (Sun), AIX (IBM), HP-UX (HP), Xenix (Microsoft).
- 1988: POSIX standard defined a common UNIX interface.
- 1991: Linus Torvalds created Linux, a free UNIX-like kernel; with GNU tools it became a complete free OS.
- Today: UNIX ideas live in Linux, macOS (based on BSD/Darwin), Android and most servers.

Q: Q6. Explain the key features of the UNIX Operating System.

Key features of the UNIX Operating System

1. Multi-user - many users can work on the same computer at the same time from different terminals.
2. Multitasking - one user can run several programs (processes) at once, e.g. in the background with &.
3. Portability - written mostly in C, so it can be moved to different hardware with little change.
4. Hierarchical file system - files are organised in a tree starting from root (/).
5. Shell (command interpreter) - powerful command language; shell scripts automate tasks.

8. Device independence - devices are treated as files (/dev), so the same commands work for files and devices.
9. Networking - built-in support for TCP/IP, remote login, file transfer.
10. Large set of utilities - grep, sed, awk, sort, cut, find, etc.
11. Time-sharing and process management - fair CPU sharing among processes.

Q: Q7. Explain the type of the Shell with a suitable example.

Types of Shell (with example)

A shell is the command interpreter: it reads commands typed by the user and asks the kernel to execute them. It is also a programming language for writing shell scripts.

1. Bourne Shell (sh) - written by Stephen Bourne at Bell Labs; the original standard shell. Prompt: $. Path: /bin/sh.
2. C Shell (csh) - written by Bill Joy (BSD); syntax similar to C language; added history and aliases. Prompt: %.
3. Korn Shell (ksh) - written by David Korn (AT&T); compatible with Bourne shell plus C-shell features (history, aliases, arithmetic).
4. Bourne Again Shell (bash) - GNU project; default shell on most Linux systems. Combines sh, csh and ksh features: command history, tab completion, arrays. Path: /bin/bash.
5. TC Shell (tcsh) - improved C shell with command-line editing.
6. Z Shell (zsh) - extended shell with plugins and themes; default on new macOS.

Example:
  echo $SHELL            # shows current shell, e.g. /bin/bash
  cat /etc/shells        # lists installed shells
  bash                   # start a bash shell
  #!/bin/bash            # first line of a script selects the shell
  echo "Hello from bash"

Q: Q8. Explain the Kernel Architecture with a neat diagram.
==============================================================================

----- FILE: code/UX-T1-08/answer.txt -----
Q: Q8. Explain the Kernel Architecture with a neat diagram.

Kernel Architecture of UNIX (with diagram)

The kernel is the core of UNIX. It is loaded into memory at boot and stays there. It directly controls the hardware and provides services to programs through system calls.

Diagram (layers):
  +-----------------------------------------------+
  |        Users / Application programs           |
  |   (shell, editors, compilers, a.out ...)      |
  +-----------------------------------------------+
  |        Libraries (libc)                       |
  +=========== System Call Interface =============+
  |                 KERNEL                        |
  |  +-------------------+  +-------------------+ |
  |  | File Subsystem    |  | Process Control   | |
  |  |  - buffer cache   |  |   Subsystem       | |
  |  |  - inode, files   |  |  - scheduler      | |
  |  +-------------------+  |  - memory mgmt    | |
  |  | Device drivers    |  |  - IPC            | |
  |  | (char / block)    |  +-------------------+ |
  |  +-------------------+                        |
  |        Hardware Control                       |
  +-----------------------------------------------+
  |                 HARDWARE                      |
  +-----------------------------------------------+

Parts:
1. System call interface - the only entry into the kernel (open, read, write, fork, exec, exit).
2. File subsystem - manages files, directories, inodes, free space and the buffer cache; talks to block/character device drivers.
3. Process control subsystem - process creation (fork), scheduling, memory management (swapping/paging) and inter-process communication (pipes, signals, messages).
4. Device drivers - control disks, terminals, printers.
5. Hardware control - handles interrupts and talks to the machine.

User programs run in user mode; the kernel runs in kernel (privileged) mode.

UX-T1-09  Explain the different Types of Kernel with suitable examples.
Q: Q9. Explain the different Types of Kernel with suitable examples.
==============================================================================

----- FILE: code/UX-T1-09/answer.txt -----
Q: Q9. Explain the different Types of Kernel with suitable examples.

Types of Kernel (with examples)

1. Monolithic kernel - the whole OS (file system, process management, memory, drivers) runs as one large program in kernel space. Fast because there is no message passing, but a bug in one part can crash the system.
   Examples: traditional UNIX, Linux, MS-DOS.

2. Microkernel - only the minimum (IPC, basic scheduling, low-level memory) runs in kernel space; file systems, drivers and services run as separate user-space servers. More reliable and secure, but slower due to message passing.
   Examples: Mach, MINIX 3, QNX, L4.

3. Hybrid kernel - mixes both: a microkernel-like design but with some services in kernel space for speed.
   Examples: Windows NT/10/11, macOS XNU.

4. Exokernel - very small kernel that only protects and allocates hardware; applications manage resources themselves through library OSes.
   Example: MIT Exokernel (research).

5. Nanokernel - extremely small kernel handling only interrupts and timing; used in embedded systems.

Comparison: monolithic = fast, less modular; microkernel = modular, stable, slower; hybrid = balance.

----- FILE: code/UX-T2-01/answer.txt -----
Q: Q1. What is the login process in UNIX? Explain its purpose.

Login process in UNIX and its purpose

When a UNIX system starts, init (or systemd) starts a getty process for each terminal.
1. getty displays the "login:" prompt and reads the user name.
2. getty runs the login program, which asks for the password.
3. login checks the user name and password against /etc/passwd and /etc/shadow.
4. If correct, login sets the user ID, group ID, home directory and environment (HOME, PATH, SHELL) and starts the user's shell (e.g. /bin/bash) in the home directory.
5. The shell runs startup files (.profile, .bashrc) and shows the prompt ($).

Purpose: to identify and authenticate the user, protect the system from unauthorised access, and give each user their own environment, files and permissions.

Q: Q2. Define an I-node. What information does it store?

I-node (index node) and the information it stores

An inode is a data structure on disk that stores all information about a file except its name and its data. Every file has a unique inode number within a file system. The directory entry links the file name to the inode number.

Information stored in an inode:
1. File type (regular file, directory, link, device)
2. File permissions (rwx for owner, group, others)
3. Owner user ID (UID) and group ID (GID)
4. File size in bytes
5. Number of hard links
6. Time stamps: last access (atime), last modification (mtime), last inode change (ctime)
7. Addresses of the disk blocks holding the data (direct, single, double and triple indirect pointers)

Command to see inode numbers: ls -i ;  details: stat filename

Q: Q3. Explain the purpose of the init process in UNIX.
==============================================================================

----- FILE: code/UX-T2-03/answer.txt -----
Q: Q3. Explain the purpose of the init process in UNIX.

Purpose of the init process in UNIX

- init is the first user-level process started by the kernel at boot. Its process ID (PID) is 1.
- It is the parent (ancestor) of all other processes.
- It reads its configuration (/etc/inittab in System V, or unit files in systemd) and decides the run level / target.
- It starts system services (daemons) and the getty processes that show the login prompt on terminals.
- It adopts orphan processes (whose parent has died) and collects their exit status, removing zombie processes.
- During shutdown or reboot it stops services and processes in an orderly way.

On modern Linux, init is usually systemd (still PID 1).

----- FILE: code/UX-T2-04/answer.txt -----
Q: Q4. What are file access permissions? Name the three basic permission types.

File access permissions

File permissions decide who can do what with a file or directory. UNIX defines permissions for three classes of users:
- Owner (u) - the user who owns the file
- Group (g) - users in the file's group
- Others (o) - all other users

Three basic permission types:
1. Read (r = 4) - file: view contents; directory: list its files.
2. Write (w = 2) - file: change contents; directory: create/delete files in it.
3. Execute (x = 1) - file: run it as a program; directory: enter it with cd.

Example: ls -l shows  -rwxr-xr--  meaning owner rwx, group r-x, others r--.

==============================================================================

----- FILE: code/UX-T2-05/answer.txt -----
Q: Q5. Differentiate between logging out and shutting down a UNIX system.

Logging out vs shutting down a UNIX system

Logging out:
- Ends only the current user's session (their shell and processes).
- Command: logout, exit, or Ctrl+D.
- The system keeps running; other users stay logged in; a new login prompt appears.
- Any user can log out.

Shutting down:
- Stops the whole system: all users are logged out, all processes and services are stopped, file systems are unmounted, then power is turned off (or the machine reboots).
- Commands: shutdown -h now, halt, poweroff, shutdown -r now / reboot.
- Normally only the superuser (root) can shut down.
- Proper shutdown is needed to avoid data loss and file-system damage.

----- FILE: code/UX-T2-07/answer.txt -----
Q: B2. Define an I-node. Explain its functions and the information stored in it.

I-node: definition, functions and information stored

Definition: an inode (index node) is a fixed-size structure in the file system that describes one file. It holds the file's metadata and the location of its data blocks, but not its name. Directory entries map names to inode numbers.

Information stored:
1. File type and permission bits (mode)
2. Owner UID and group GID
3. File size
4. Link count (number of hard links)
5. Time stamps: atime (last access), mtime (last data modification), ctime (last inode change)
6. Data block pointers: 12 direct pointers + single, double and triple indirect pointers (classic UNIX design)

Functions / uses:
1. Locating data - the kernel uses the block pointers to read and write the file's data.
2. Access control - permission bits and owner decide who can read/write/execute.
3. Hard links - many names (directory entries) can point to the same inode; the file is deleted only when the link count becomes 0.
4. Fast metadata operations - ls -l, stat, find read the inode without reading the data.
5. Rename/move within the same file system only changes the directory entry, not the inode or data.

Diagram:
  Directory entry            Inode 1234                 Data blocks
  +----------------+     +------------------+       +-----------+
  | "notes.txt" 1234 |-->| type, perms, uid |  ---> | block 501 |
  +----------------+     | size, links, times|  ---> | block 502 |
                         | block pointers   |       +-----------+
                         +------------------+

Commands:  ls -i file  (inode number);  stat file  (all inode details);  df -i  (inode usage).

----- FILE: code/UX-T2-08/answer.txt -----
Q: B3. Explain the UNIX file system hierarchy and describe the purpose of important directories.

UNIX file system hierarchy and important directories

UNIX uses a single inverted-tree hierarchy starting at root (/). All files, devices and mounted disks appear under it.

                    /
  +-----+-----+-----+-----+-----+-----+-----+-----+
 bin  sbin  etc  home  dev  lib  tmp  usr  var  boot ...

Important directories:
- /       Root of the whole file system.
- /bin    Essential user commands (ls, cp, mv, cat, bash).
- /sbin   System administration commands (shutdown, fdisk, ifconfig).
- /etc    System configuration files (passwd, shadow, hosts, fstab).
- /home   Home directories of users (/home/shivam).
- /root   Home directory of the superuser.
- /dev    Device files (/dev/sda disk, /dev/tty terminals, /dev/null).
- /lib    Shared libraries needed by /bin and /sbin programs, kernel modules.
- /usr    User programs and data: /usr/bin, /usr/lib, /usr/share, /usr/local.
- /var    Variable data: logs (/var/log), mail, spool, caches.
- /tmp    Temporary files; often cleared at reboot.
- /boot   Boot loader files and the kernel image.
- /opt    Optional add-on application software.
- /mnt, /media  Mount points for temporary file systems, USB drives, CD-ROMs.
- /proc   Virtual file system with process and kernel information.

Paths: absolute path starts from / (e.g. /home/shivam/a.txt); relative path starts from the current directory (e.g. docs/a.txt).

==============================================================================

----- FILE: code/UX-T2-09/answer.txt -----
Q: B4. Explain the stages of the UNIX booting process and the role of the init process.

Stages of the UNIX booting process and the role of init

1. BIOS / UEFI (firmware)
   - Power-on self test (POST) checks hardware.
   - Finds the boot device and loads the boot loader from the boot sector (MBR) or EFI partition.
2. Boot loader (e.g. GRUB / LILO)
   - Shows boot menu, loads the kernel image (/boot/vmlinuz) and initial RAM disk (initrd) into memory and passes control to the kernel.
3. Kernel initialisation
   - Detects and initialises CPU, memory and devices, loads drivers, mounts the root file system (/) read-only, then starts the first process: /sbin/init (PID 1).
4. init (or systemd)
   - Reads /etc/inittab (System V) or its units (systemd).
   - Decides run level / target: 0 halt, 1 single-user, 3 multi-user text, 5 graphical, 6 reboot.
   - Runs start-up scripts (/etc/rc.d, /etc/init.d) to check and mount file systems, start networking and daemons (cron, sshd, printing).
5. getty and login
   - init starts getty on each terminal, which shows the login: prompt; after login the user's shell starts.

Role of init: it is the first process (PID 1) and parent of all processes; it brings the system to the required run level, starts and supervises services, starts login terminals, adopts orphan processes and handles orderly shutdown/reboot.

UX-T2-10  Explain UNIX file permissions using symbolic and numeric methods with examples.

==============================================================================

----- FILE: code/UX-T2-10/answer.txt -----
Q: B5. Explain UNIX file permissions using symbolic and numeric methods with examples.

UNIX file permissions: symbolic and numeric methods (with examples)

ls -l output:   -rwxr-x---  1 shivam staff 120 Oct 15 a.sh
 - first character: file type (- file, d directory, l link)
 - next 9 characters: owner (rwx), group (r-x), others (---)

Permission values: r = 4, w = 2, x = 1, - = 0

1) Symbolic method   chmod [who][operator][permissions] file
   who: u (owner), g (group), o (others), a (all)
   operator: + add, - remove, = set exactly
   Examples:
     chmod u+x a.sh          # give owner execute
     chmod g-w notes.txt     # remove write from group
     chmod o=r notes.txt     # others get read only
     chmod a+r notes.txt     # everyone can read
     chmod u=rwx,g=rx,o= a.sh

2) Numeric (octal) method   chmod NNN file
   Each digit = sum of r(4) + w(2) + x(1), in order owner, group, others.
   Examples:
     chmod 755 a.sh     # rwx r-x r-x  (7=4+2+1, 5=4+1)
     chmod 644 a.txt    # rw- r-- r--
     chmod 700 secret   # rwx --- ---
     chmod 777 file     # rwx rwx rwx (everyone full access, not safe)

Related commands:
     ls -l file            # display permissions
     chown user file       # change owner
     chgrp group file      # change group
     umask 022             # default permissions for new files (666-022 = 644)
