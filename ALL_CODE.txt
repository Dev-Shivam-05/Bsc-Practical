UX-A2-01  Arithmetic operations
Q: Write a shell script to accept two numbers and perform addition, subtraction, multiplication, division, and modulus using arithmetic operators.
==============================================================================

----- FILE: code/UX-A2-01/q01.sh -----
#!/usr/bin/env bash
read -r -p "Enter two integers: " a b
if ! [[ $a =~ ^-?[0-9]+$ && $b =~ ^-?[0-9]+$ ]]; then
  echo "Please enter valid integers."; exit 1
fi
echo "Addition: $((a + b))"
echo "Subtraction: $((a - b))"
echo "Multiplication: $((a * b))"

  echo "Division and modulus are undefined for zero divisor."
else
  echo "Division: $((a / b))"
  echo "Modulus: $((a % b))"
fi

  [[ $n =~ ^-?[0-9]+$ ]] || { echo "Invalid integer."; exit 1; }

UX-A2-12  Menu-driven calculator (case)
Q: Write a menu-driven shell script using case to perform addition, subtraction, multiplication, division, modulus, and exit operations.
==============================================================================

----- FILE: code/UX-A2-12/q12.sh -----
#!/usr/bin/env bash
while true; do
  printf '\n1. Add  2. Subtract  3. Multiply  4. Divide\n'
  printf '5. Modulus  6. Exit\n'
  read -r -p "Choose 1-6: " choice
  case "$choice" in
    6) echo "Goodbye"; break ;;
    1|2|3|4|5) ;;
    *) echo "Invalid choice"; continue ;;
  esac
  read -r -p "Enter two integers: " a b
  if ! [[ $a =~ ^-?[0-9]+$ && $b =~ ^-?[0-9]+$ ]]; then
    echo "Invalid integer input"; continue
  fi
  if [[ $choice == 4 || $choice == 5 ]] && ((b == 0)); then
    echo "Cannot use zero as divisor"; continue
  fi
  case "$choice" in
    1) answer=$((a+b)) ;; 2) answer=$((a-b)) ;;
    3) answer=$((a*b)) ;; 4) answer=$((a/b)) ;;
    5) answer=$((a%b)) ;;
  esac
  echo "Result: $answer"
done

#!/usr/bin/env bash
read -r -p "Enter path: " path
if [[ ! -e $path ]]; then echo "Path does not exist"; exit 0; fi
echo "Path exists"
if [[ -f $path ]]; then echo "Regular file";
elif [[ -d $path ]]; then echo "Directory";
else echo "Other file type"; fi
for mode in read write execute; do
  case "$mode" in
    read)    testflag=-r ;; write) testflag=-w ;;
    execute) testflag=-x ;;
  esac
  if test "$testflag" "$path"; then
    echo "$mode permission: yes"
  else
    echo "$mode permission: no"
  fi
done

#!/usr/bin/env bash
factorial() {
  local n=$1 result=1 i
  if ! [[ $n =~ ^[0-9]+$ ]]; then
    echo "Factorial requires a non-negative integer"; return 1
  fi
  for ((i=2; i<=n; i++)); do ((result *= i)); done
  printf 'Factorial of %d = %d\n' "$n" "$result"
}

UX-P2-09  Menu-driven calculator (same as UX-A2-12)
Q: Create a menu-driven calculator using the case statement for: Addition, Subtraction, Multiplication, Division, Exit
==============================================================================

----- FILE: code/UX-P2-09/q12.sh -----
#!/usr/bin/env bash
while true; do
  printf '\n1. Add  2. Subtract  3. Multiply  4. Divide\n'
  printf '5. Modulus  6. Exit\n'
  read -r -p "Choose 1-6: " choice
  case "$choice" in
    6) echo "Goodbye"; break ;;
    1|2|3|4|5) ;;
    *) echo "Invalid choice"; continue ;;
  esac
  read -r -p "Enter two integers: " a b
  if ! [[ $a =~ ^-?[0-9]+$ && $b =~ ^-?[0-9]+$ ]]; then
    echo "Invalid integer input"; continue
  fi
  if [[ $choice == 4 || $choice == 5 ]] && ((b == 0)); then
    echo "Cannot use zero as divisor"; continue
  fi
  case "$choice" in
    1) answer=$((a+b)) ;; 2) answer=$((a-b)) ;;
    3) answer=$((a*b)) ;; 4) answer=$((a/b)) ;;
    5) answer=$((a%b)) ;;
  esac
  echo "Result: $answer"
done

Program 4 - Demonstrate MSIL compilation
==========================================

1. Compile the VB source to an assembly (MSIL inside a PE file):
     C:\Windows\Microsoft.NET\Framework64\v4.0.30319\vbc.exe /target:exe /out:Hello.exe Hello.vb
   (In "Developer Command Prompt for VS" you can type just: vbc /target:exe /out:Hello.exe Hello.vb)

2. Run it (the CLR JIT-compiles the IL to native code at run time):
     Hello.exe
   Expected output:  Hello from managed .NET code

3. Inspect the MSIL with ildasm:
     GUI : ildasm Hello.exe        -> expand "Hello" -> double-click "Main : void()"
     Text: ildasm /text Hello.exe   (prints the IL to the console)
   ildasm is not on the normal PATH. Full path on a machine with Visual Studio / .NET SDK:
     "C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8.1 Tools\ildasm.exe"

   Expected IL for Main (verified):
     IL_0000:  ldstr      "Hello from managed .NET code"
     IL_0005:  call       void [mscorlib]System.Console::WriteLine(string)
     IL_000a:  ret

If Windows blocks Hello.exe ("file contains a virus or potentially unwanted software",
caused by Smart App Control / Defender on brand-new unsigned exe files), build a DLL instead
and inspect that - the IL of Main is identical:
     vbc /target:library /out:HelloLib.dll Hello.vb
     ildasm /text HelloLib.dll

Imports System.Configuration
Imports System.Data
Imports System.Data.SqlClient

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

Imports System.Configuration
Imports System.Data
Imports System.Data.SqlClient

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

Imports System
Imports System.Data
Imports System.Data.SqlClient
Imports System.Globalization

Partial Class Prog4
    Inherits System.Web.UI.Page

    Protected Sub Page_Load(sender As Object, e As EventArgs)
        If Not IsPostBack Then BindGrid()
    End Sub

    Private Sub BindGrid()
        gvData.DataSource = Db.ReadTable(
            "SELECT * FROM Employee ORDER BY EmployeeID")
        gvData.DataBind()
    End Sub

    Private Function FormParams() As SqlParameter()
        If String.IsNullOrWhiteSpace(txtEmployeeName.Text) Then
            Throw New ArgumentException("Employee name is required.")
        End If
        If String.IsNullOrWhiteSpace(txtDepartment.Text) Then
            Throw New ArgumentException("Department is required.")
        End If
        If String.IsNullOrWhiteSpace(txtSalary.Text) Then
            Throw New ArgumentException("Salary is required.")
        End If
        If String.IsNullOrWhiteSpace(txtContactNo.Text) Then
            Throw New ArgumentException("Contact no. is required.")
        End If
        Return New SqlParameter() {
            New SqlParameter("@EmployeeName", txtEmployeeName.Text.Trim()),
            New SqlParameter("@Department", txtDepartment.Text.Trim()),
            New SqlParameter("@Salary", Decimal.Parse(txtSalary.Text, CultureInfo.InvariantCulture)),
            New SqlParameter("@ContactNo", txtContactNo.Text.Trim())
        }
    End Function

    Private Sub ResetForm()
        txtEmployeeName.Text = ""
        txtDepartment.Text = ""
        txtSalary.Text = ""
        txtContactNo.Text = ""
        hfKey.Value = ""
        gvData.SelectedIndex = -1
    End Sub

    Protected Sub btnAdd_Click(sender As Object, e As EventArgs)
        Try
            Db.Execute("INSERT INTO Employee (EmployeeName,Department,Salary,ContactNo) " &
                "VALUES (@EmployeeName,@Department,@Salary,@ContactNo)", FormParams())
            lblMessage.Text = "Record inserted."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Insert failed: check all field values."
        End Try
    End Sub

    Protected Sub btnUpdate_Click(sender As Object, e As EventArgs)
        If hfKey.Value = "" Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Try
            Dim ps As New List(Of SqlParameter)(FormParams())
            ps.Add(New SqlParameter("@Key", Integer.Parse(hfKey.Value)))
            Db.Execute("UPDATE Employee SET EmployeeName=@EmployeeName,Department=@Department,Salary=@Salary,ContactNo=@ContactNo WHERE EmployeeID=@Key", ps.ToArray())
            lblMessage.Text = "Record updated."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Update failed: check all field values."
        End Try
    End Sub

    Protected Sub btnDelete_Click(sender As Object, e As EventArgs)
        Dim key As Integer
        If Not Integer.TryParse(hfKey.Value, key) Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Db.Execute("DELETE FROM Employee WHERE EmployeeID=@Key",
            New SqlParameter("@Key", key))
        lblMessage.Text = "Record deleted."
        ResetForm()
        BindGrid()
    End Sub

    Protected Sub btnClear_Click(sender As Object, e As EventArgs)
        ResetForm()
        lblMessage.Text = ""
    End Sub

    Protected Sub gvData_SelectedIndexChanged(sender As Object, e As EventArgs)
        Dim key As Integer = Convert.ToInt32(gvData.SelectedDataKey.Value)
        Dim data As DataTable = Db.ReadTable(
            "SELECT * FROM Employee WHERE EmployeeID=@Key",
            New SqlParameter("@Key", key))
        If data.Rows.Count = 0 Then Return
        Dim row As DataRow = data.Rows(0)
        hfKey.Value = key.ToString()
        txtEmployeeName.Text = row("EmployeeName").ToString()
        txtDepartment.Text = row("Department").ToString()
        txtSalary.Text = row("Salary").ToString()
        txtContactNo.Text = row("ContactNo").ToString()
    End Sub
End Class

Imports System.Configuration

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

    Inherits System.Web.UI.Page

        If Not IsPostBack Then BindGrid()
    End Sub

    Private Sub BindGrid()
        gvData.DataSource = Db.ReadTable(
            "SELECT * FROM Customer ORDER BY CustomerID")
        gvData.DataBind()
    End Sub

    Private Function FormParams() As SqlParameter()
        If String.IsNullOrWhiteSpace(txtCustomerName.Text) Then
            Throw New ArgumentException("Customer name is required.")
        End If
        If String.IsNullOrWhiteSpace(txtEmail.Text) Then
            Throw New ArgumentException("Email is required.")
        End If
        If String.IsNullOrWhiteSpace(txtPhone.Text) Then
            Throw New ArgumentException("Phone is required.")
        End If
        If String.IsNullOrWhiteSpace(txtAddress.Text) Then
            Throw New ArgumentException("Address is required.")
        End If
        Return New SqlParameter() {
            New SqlParameter("@CustomerName", txtCustomerName.Text.Trim()),
            New SqlParameter("@Email", txtEmail.Text.Trim()),
            New SqlParameter("@Phone", txtPhone.Text.Trim()),
            New SqlParameter("@Address", txtAddress.Text.Trim())
        }
    End Function

    Private Sub ResetForm()
        txtCustomerName.Text = ""
        txtEmail.Text = ""
        txtPhone.Text = ""
        txtAddress.Text = ""
        hfKey.Value = ""
        gvData.SelectedIndex = -1
    End Sub

    Protected Sub btnAdd_Click(sender As Object, e As EventArgs)

            Db.Execute("INSERT INTO Customer (CustomerName,Email,Phone,Address) " &
                "VALUES (@CustomerName,@Email,@Phone,@Address)", FormParams())
            lblMessage.Text = "Record inserted."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Insert failed: check all field values."
        End Try
    End Sub

    Protected Sub btnUpdate_Click(sender As Object, e As EventArgs)
        If hfKey.Value = "" Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Try
            Dim ps As New List(Of SqlParameter)(FormParams())
            ps.Add(New SqlParameter("@Key", Integer.Parse(hfKey.Value)))
            Db.Execute("UPDATE Customer SET CustomerName=@CustomerName,Email=@Email,Phone=@Phone,Address=@Address WHERE CustomerID=@Key", ps.ToArray())
            lblMessage.Text = "Record updated."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Update failed: check all field values."
        End Try
    End Sub

    Protected Sub btnDelete_Click(sender As Object, e As EventArgs)
        Dim key As Integer
        If Not Integer.TryParse(hfKey.Value, key) Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Db.Execute("DELETE FROM Customer WHERE CustomerID=@Key",
            New SqlParameter("@Key", key))
        lblMessage.Text = "Record deleted."
        ResetForm()
        BindGrid()
    End Sub

    Protected Sub btnClear_Click(sender As Object, e As EventArgs)
        ResetForm()
        lblMessage.Text = ""
    End Sub

Imports System.Configuration
Imports System.Data
Imports System.Data.SqlClient

Public NotInheritable Class Db
    Private Sub New()
    End Sub

    Private Shared ReadOnly ConnectionText As String =
        ConfigurationManager.ConnectionStrings("con").ConnectionString

    Public Shared Function ReadTable(query As String,
                                     ParamArray args() As SqlParameter) As DataTable
        Dim result As New DataTable()
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                Using adapter As New SqlDataAdapter(cmd)
                    adapter.Fill(result)
                End Using
            End Using
        End Using
        Return result
    End Function

    Public Shared Function Execute(query As String,
                                   ParamArray args() As SqlParameter) As Integer
        Using con As New SqlConnection(ConnectionText)
            Using cmd As New SqlCommand(query, con)
                If args.Length > 0 Then cmd.Parameters.AddRange(args)
                con.Open()
                Return cmd.ExecuteNonQuery()
            End Using
        End Using
    End Function
End Class

Imports System
Imports System.Data
Imports System.Data.SqlClient
Imports System.Globalization

Partial Class Prog7
    Inherits System.Web.UI.Page

    Protected Sub Page_Load(sender As Object, e As EventArgs)
        If Not IsPostBack Then BindGrid()
    End Sub

    Private Sub BindGrid()
        gvData.DataSource = Db.ReadTable(
            "SELECT * FROM Medicine ORDER BY MedicineID")
        gvData.DataBind()
    End Sub

    Private Function FormParams() As SqlParameter()
        If String.IsNullOrWhiteSpace(txtMedicineName.Text) Then
            Throw New ArgumentException("Medicine name is required.")
        End If
        If String.IsNullOrWhiteSpace(txtCategory.Text) Then
            Throw New ArgumentException("Category is required.")
        End If
        If String.IsNullOrWhiteSpace(txtPrice.Text) Then
            Throw New ArgumentException("Price is required.")
        End If
        If String.IsNullOrWhiteSpace(txtQuantity.Text) Then
            Throw New ArgumentException("Quantity is required.")
        End If
        If String.IsNullOrWhiteSpace(txtExpiryDate.Text) Then
            Throw New ArgumentException("Expiry date is required.")
        End If
        Return New SqlParameter() {
            New SqlParameter("@MedicineName", txtMedicineName.Text.Trim()),
            New SqlParameter("@Category", txtCategory.Text.Trim()),
            New SqlParameter("@Price", Decimal.Parse(txtPrice.Text, CultureInfo.InvariantCulture)),
            New SqlParameter("@Quantity", Integer.Parse(txtQuantity.Text, CultureInfo.InvariantCulture)),
            New SqlParameter("@ExpiryDate", DateTime.ParseExact(txtExpiryDate.Text, "yyyy-MM-dd", CultureInfo.InvariantCulture))
        }
    End Function

    Private Sub ResetForm()
        txtMedicineName.Text = ""
        txtCategory.Text = ""
        txtPrice.Text = ""
        txtQuantity.Text = ""
        txtExpiryDate.Text = ""
        hfKey.Value = ""
        gvData.SelectedIndex = -1
    End Sub

    Protected Sub btnAdd_Click(sender As Object, e As EventArgs)
        Try
            Db.Execute("INSERT INTO Medicine (MedicineName,Category,Price,Quantity,ExpiryDate) " &
                "VALUES (@MedicineName,@Category,@Price,@Quantity,@ExpiryDate)", FormParams())
            lblMessage.Text = "Record inserted."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Insert failed: check all field values."
        End Try
    End Sub

    Protected Sub btnUpdate_Click(sender As Object, e As EventArgs)
        If hfKey.Value = "" Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Try
            Dim ps As New List(Of SqlParameter)(FormParams())
            ps.Add(New SqlParameter("@Key", Integer.Parse(hfKey.Value)))
            Db.Execute("UPDATE Medicine SET MedicineName=@MedicineName,Category=@Category,Price=@Price,Quantity=@Quantity,ExpiryDate=@ExpiryDate WHERE MedicineID=@Key", ps.ToArray())
            lblMessage.Text = "Record updated."
            ResetForm()
            BindGrid()
        Catch ex As Exception
            lblMessage.Text = "Update failed: check all field values."
        End Try
    End Sub

    Protected Sub btnDelete_Click(sender As Object, e As EventArgs)
        Dim key As Integer
        If Not Integer.TryParse(hfKey.Value, key) Then
            lblMessage.Text = "Select a record first."
            Return
        End If
        Db.Execute("DELETE FROM Medicine WHERE MedicineID=@Key",
            New SqlParameter("@Key", key))
        lblMessage.Text = "Record deleted."
        ResetForm()
        BindGrid()
    End Sub

    Protected Sub btnClear_Click(sender As Object, e As EventArgs)
        ResetForm()
        lblMessage.Text = ""
    End Sub

    Protected Sub gvData_SelectedIndexChanged(sender As Object, e As EventArgs)
        Dim key As Integer = Convert.ToInt32(gvData.SelectedDataKey.Value)
        Dim data As DataTable = Db.ReadTable(
            "SELECT * FROM Medicine WHERE MedicineID=@Key",
            New SqlParameter("@Key", key))
        If data.Rows.Count = 0 Then Return
        Dim row As DataRow = data.Rows(0)
        hfKey.Value = key.ToString()
        txtMedicineName.Text = row("MedicineName").ToString()
        txtCategory.Text = row("Category").ToString()
        txtPrice.Text = row("Price").ToString()
        txtQuantity.Text = row("Quantity").ToString()
        txtExpiryDate.Text = CDate(row("ExpiryDate")).ToString("yyyy-MM-dd")
    End Sub
End Class

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;
}

<?php
declare(strict_types=1);

function db(array $model): PDO {
    static $db = null;
    if ($db instanceof PDO) return $db;
    $host = getenv('DB_HOST') ?: '127.0.0.1';
    $user = getenv('DB_USER') ?: 'root';
    $pass = getenv('DB_PASSWORD') ?: '';
    $database = $model['database'];
    $dsn = "mysql:host=$host;dbname=$database;charset=utf8mb4";
    $db = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]);

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;
}

<?php
declare(strict_types=1);

function db(array $model): PDO {
    static $db = null;
    if ($db instanceof PDO) return $db;
    $host = getenv('DB_HOST') ?: '127.0.0.1';
    $user = getenv('DB_USER') ?: 'root';
    $pass = getenv('DB_PASSWORD') ?: '';
    $database = $model['database'];
    $dsn = "mysql:host=$host;dbname=$database;charset=utf8mb4";
    $db = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]);
    return $db;
}

        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];

function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }

function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;

<?php
function render_rows(array $records, array $model): void {
    if (!$records) {
        echo '<tr><td colspan="' . (count($model['fields']) + 2) . '">'
            . 'No matching records.</td></tr>';
        return;

    foreach ($records as $row) {

            echo '<td>' . e($row[$name]) . '</td>';

function render_rows(array $records, array $model): void {
    if (!$records) {
        echo '<tr><td colspan="' . (count($model['fields']) + 2) . '">'

}

<?php
declare(strict_types=1);

session_start();
$model = require __DIR__ . '/model.php';
require_once __DIR__ . '/db.php';

function e($value): string {
    return htmlspecialchars((string)$value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
function token(): string {
    if (empty($_SESSION['csrf'])) {
        $_SESSION['csrf'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf'];
}
function check_token(): void {
    if (!hash_equals(token(), (string)($_POST['csrf'] ?? ''))) {
        http_response_code(403); exit('Invalid CSRF token.');
    }
}
function positive_id($input): int {
    $id = filter_var($input, FILTER_VALIDATE_INT);
    if ($id === false || $id < 1) {
        http_response_code(400); exit('Invalid record identifier.');
    }
    return $id;
}
function validate_input(array $model): array {
    $values = [];
    foreach ($model['fields'] as $key => $definition) {
        $value = trim((string)($_POST[$key] ?? ''));
        if ($value === '') {
            throw new InvalidArgumentException($definition['label'] . ' is required.');
        }
        switch ($definition['type']) {
            case 'email':
                if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    throw new InvalidArgumentException('Invalid email address.');
                }
                break;
            case 'number':
                if (!is_numeric($value) || (float)$value < 0) {
                    throw new InvalidArgumentException('Invalid amount.');
                }
                break;
            case 'integer':
                if (!ctype_digit($value)) {
                    throw new InvalidArgumentException('Enter a non-negative integer.');
                }
                break;
        }
        if (strlen($value) > ($definition['max'] ?? 1000)) {
            throw new InvalidArgumentException($definition['label'] . ' is too long.');
        }
        $values[$key] = $value;
    }
    return $values;
}
function fetch_rows(array $model, string $search = ''): array {
    $table = $model['table'];
    $order = $model['order'];
    $sql = "SELECT * FROM `$table`";
    $params = [];
    if ($search !== '' && !empty($model['search'])) {
        $clauses = [];
        foreach ($model['search'] as $i => $column) {
            $placeholder = ":q$i";
            $clauses[] = "`$column` LIKE $placeholder";
            $params[$placeholder] = '%' . $search . '%';
        }
        $sql .= ' WHERE ' . implode(' OR ', $clauses);
    }
    $sql .= " ORDER BY `$order` ASC";
    $stmt = db($model)->prepare($sql);
    $stmt->execute($params);
    return $stmt->fetchAll();
}
function goto_home(): void {
    header('Location: index.php');
    exit;
}

<?php
declare(strict_types=1);

function db(array $model): PDO {
    static $db = null;
    if ($db instanceof PDO) return $db;
    $host = getenv('DB_HOST') ?: '127.0.0.1';
    $user = getenv('DB_USER') ?: 'root';
    $pass = getenv('DB_PASSWORD') ?: '';
    $database = $model['database'];
    $dsn = "mysql:host=$host;dbname=$database;charset=utf8mb4";
    $db = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false,
    ]);
    return $db;
}
